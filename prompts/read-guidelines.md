- read: call it only for information the tool never served you, such as content past the auto-read diff. A bash view or an auto-read already served the file, so edit from those rows.
- read: when you need several blocks or both boundaries of one replacement, put every range in ONE call. Use `{ file, windows: [{ offset, limit }] }`. Each window is served in that turn, so its anchors work in the same edit. A window can also be `{ around_anchor, radius }` to centre on a line this session already served. An anchor outside this session's served rows is omitted with an inline `[Window warning: ...]`.
- read: pass `mode: "outline"` to orient in a file without reading bodies; it serves symbol declaration lines as live anchors. Pass `mode: "verbatim"` for plain text with no anchors when you will not edit (e.g. config, docs, README, SKILL.md). Omit `mode` when you intend to edit, so the rows carry anchors.
- read: send one file per call as `{ file, windows?, mode? }`, the same way `edit` does. The single top-level `mode` applies to the file. To read several files, make parallel `read` calls.
- read: PNG/JPG images return as image attachments for multimodal models. Request one with `file` like any other file.
