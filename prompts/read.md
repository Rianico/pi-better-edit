Read one or more text files in one call via `files: [{ file, windows?, mode? }, ...]` (at most 10 files). By default each line returns as HASH│content with a 4-char alphanumeric hash — keep the default when you intend to edit the file, and use the HASH as the anchor in edit calls; pass `mode: "verbatim"` for plain file content with no HASH│ prefix when you will not edit the file. Every file renders under a `[path (N lines total)]` header (`[path (verbatim, N lines, no anchors)]` in verbatim) and each window under `=== Lines s-e of N ===`; rows stay `HASH│content` with no row-level line numbers. Name ranges with `windows`: `[{ offset, limit }]` (offset is 1-indexed, limit a line count) or `[{ around_anchor: "a1b2", radius: 10 }]` to centre on a line this session served; at most 16 windows across the whole call. When a page stops short, its footer `[path lines s-e of N. Use windows: [{ offset, limit }] to continue.]` is the exact continuation to pass back. A file that cannot be read reports its error in its own section and every sibling still renders. Empty files return `HASH│` (edit to insert), or `[File is empty.]` with `mode: "verbatim"`. Plain text only (no line numbers). Binary/directory and UTF-16/UTF-32 files are rejected. A UTF-8 BOM is stripped; non-UTF-8 bytes are shown as U+FFFD. To load skill content as plain text, use `read` with `mode: "verbatim"` (the default `served` mode is capped at 200,000 lines by the served admission budget; `mode: "verbatim"` is not capped, though both are bounded by a 100MB size guard). Hashes are file-scoped: a 4-char anchor is bound to the file it was served from, so copy anchors only from the file you are editing.

Interop: small reads (limit <= 100) may be expanded to the enclosing AST symbol before this tool runs — the served HASH│content rows and their anchors always reflect the expanded window actually returned, so copy anchors only from the rows you received. Every default-mode row (including all windows entries and post-edit diff rows) is served and its anchor usable in the next edit with no re-read, even when truncated to what is shown.
