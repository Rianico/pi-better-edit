Edit a range of lines in a text file with the exact payload `{ "path": path, "edits": [[remove_from, remove_to, replacement_text], ...] }`. `path` is a non-empty file path or `null` to infer it from the anchors. Each `edits` item is exactly `[remove_from, remove_to, replacement_text]`: two inclusive bare 3-character HASH anchors from read output (for example `"aB3"`), never line content, and the complete replacement text (use `""` to delete). Multiple items in one call are applied in order and atomically to that one file — nothing is written unless every item verifies.
