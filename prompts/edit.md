Edit a range of lines in a text file via `edit`: `{ "file": file, "edits": [{ "anchor_from": a, "anchor_to": b, "text": text }, ...] }`. Use rows this session served for the file: `read`, a diff, or a bash view. `anchor_from`/`anchor_to` are bare 4-char HASH anchors in this file's served rows (lease (session, file, anchor)). One payload per item: `text` or `text_ref` `{anchor_from, anchor_to, mode (required), file?}`, the bytes of a served span (`mode` `"copy"` keeps it, `"cut"` removes it). `at`: "in-place" (default), "before", "after". A null optional field reads as absent. An `[E_*]` token and the line it opens are your retry instruction. `[W_*]`/`[USER]` in `content` are informational, not refusals.
