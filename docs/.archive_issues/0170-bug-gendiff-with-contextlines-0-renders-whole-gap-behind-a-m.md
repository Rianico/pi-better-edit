# [bug] genDiff with contextLines=0 renders whole gap behind a marker with desynced anchors

## Context

Found during the fix-166 review panel as a pre-existing defect adjacent to #166 (deliberately NOT fixed there — outside its blast radius).

## Analysis

In the gap-collapse step of the diff renderer, the large-gap branch computes `tail = displayLines.slice(-contextLines)`. With `contextLines=0`, `-0 === 0`, so `slice(-0)` returns the WHOLE gap: output becomes `[marker, ...allRows]` with `skipMiddle = length`. Rows render fully behind a spurious collapse marker while counters skip past them, so every later row-s content-anchor lookup is desynced — the same failure mode as #166, via a different branch.

Production-reachable: `src/edit-undo.ts:201` calls `genDiff` with context 0.

## Suggested acceptance

- [ ] Repro: two changes separated by an N-line gap at context 0 — diff either renders fully with NO marker and aligned anchors, or collapses correctly with aligned anchors (maintainer picks the contract).
- [ ] Regression test alongside `test/core/edit-diff.gap.test.ts`.
- [ ] Existing suites stay green.

Related: #166 (same file, different branch), #169 (display-vs-model split).
